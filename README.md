# DragoCrypt

## Descripción del programa
DragoCrypt es una herramienta con interfaz gráfica moderna, diseñada para insertar marcas invisibles personalizadas en archivos de cualquier tipo (STL, RAR, ZIP, imágenes, etc.), permitiendo identificar y rastrear su procedencia.
Su objetivo es ofrecer protección y trazabilidad de contenido de forma discreta, con una experiencia visual cuidada y estilo gamer/cyberpunk.

## ✨ Características principales
- 🎯 **Marcar archivos**: Inserta marcas ocultas únicas por comprador, sin alterar la usabilidad del archivo.
- 🔍 **Revisar marcas**: Detecta y verifica marcas previamente insertadas.
- 🧑‍💼 **Registro de usuarios**: Control de compradores y asignación de marcas.
- ⚙️ **Configuración avanzada**: Personaliza la apariencia y el comportamiento del programa.
- 🌗 **Modos de tema**: Oscuro, claro y sistema, seleccionables en tiempo real.

## 🖥️ Interfaz
- Diseñada con **CustomTkinter** para un estilo moderno y adaptable.
- Iconografía **neón gamer** para cada función.
- Navegación mediante **panel con scroll** y botones grandes para fácil acceso.

## 📦 Tecnologías utilizadas
- **Python 3**
- **CustomTkinter** (interfaz gráfica)
- **Pillow (PIL)** (manejo de imágenes)
- **sys** (control de cierre seguro)

## 🚀 Uso rápido
1. Ejecuta `DragoCrypt.py`.
2. Selecciona la acción deseada desde el menú principal.
3. Disfruta de la potencia de **marcado invisible** con un diseño **gamer-tech**.
